# Module 1 — Introduction to AI & Python

## Overview

This repository contains the learning notes and beginner Python programs
completed as part of the Codomax AI & Machine Learning Internship,
**Module 1: Introduction to AI & Python**.

## Structure

```text
Module-1-AI-Python/
├── notes/
│   └── notes.md                 # AI/ML/DL + Python learning notes
├── python-basics/
│   ├── variables.py
│   ├── conditions.py
│   ├── loops.py
│   ├── lists.py
│   └── functions.py
└── exercises/
    ├── calculator.py
    ├── even_odd_checker.py
    ├── number_guessing_game.py
    ├── student_grade_calculator.py
    ├── password_generator.py
    └── todo_list.py
```

## Topics covered

- Artificial Intelligence, Machine Learning, and Deep Learning fundamentals
- Real-world AI applications and ML workflow
- Python variables, data types, operators, and type conversion
- Conditional statements and loops
- Lists and list comprehensions
- Functions, input/output, and error handling (`try/except`)

## Running the programs

All programs use only Python's standard library and run with any Python
3.x version:

```bash
python variables.py
python conditions.py
python loops.py
python lists.py
python functions.py
python exercises/calculator.py
python exercises/even_odd_checker.py
python exercises/number_guessing_game.py
python exercises/student_grade_calculator.py
python exercises/password_generator.py
python exercises/todo_list.py
```
